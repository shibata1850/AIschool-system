## 前回の記録の訂正

前回の単体814件と3条件E2Eは、課題IDと提出履歴を持つ架空の採点対象小テストでの検証でした。その成功を、実教材45件の自動照合が完成したという意味では扱いません。

採点対象小テスト向けの照合コードは保持しますが、実環境の練習用小テストに流用できません。実APIで確認したのは、今回の**小テスト形式の検出と対象外判定**です。採点対象小テストの得点一致経路は引き続き架空応答での検証です。

既存の[Canvas採用方針](../../docs/step01/canvas-standard-quiz.md)には、途中確認を練習小テストとして最終成績へ加算しないことが記録されています。連携コードを動かすために、この形式や評定表への扱いを自動変更しません。
