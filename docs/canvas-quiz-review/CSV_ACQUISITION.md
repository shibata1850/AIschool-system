# 練習用小テストの分析CSVを取得して確認待ちで保存

2026-09-19。受信側の開発用パッチ。**本番未配備・受講者への公開なし。**

## 講師が行う操作

1. Canvasの分析画面で「すべての受験回」の受講者分析CSVを作成し、生成完了を待つ。
2. CANVASLMASの「小テスト結果の確認」で対象の小テストを選び、「分析CSVを取得して保存」を押す。
3. 確認待ち一覧で受験回・技能別得点・CSVファイル更新日時・取得日時を確認する。
4. 新しい受験や再採点が含まれているかはCanvasの答案画面で確認する。CSVを取得できたことだけで「最新」とは判定しない。

この変更により、作成済みCSVをPCへ保存して別途JSONへ変換する手順を省ける。旧JSON読込も残す。CSVが未作成・生成中のときは保存せず、Canvasでの作成完了を案内する。CSV作成要求・自動再生成は今回の範囲外。

## 実装と保存内容

- `POST /api/teacher/quiz-review/acquire` は小テスト番号だけを受け取る。送信元、LTI講師権限、Canvas上の現在の担当コースを確認し、登録済み45小テストの範囲で取得する。
- Canvasへの通信はGETのみ。`student_analysis`、`includes_all_versions=true`、対象小テスト、非匿名、生成完了を検査。レポート一覧・生成状態・ファイル・取得後のレポートを確認する。
- ファイルURLは設定済みCanvasオリジンの `/files/{当該fileId}/download` のみ。同じホストにだけ既存API認証を送り、リダイレクトを拒否する。外部ストレージや別ホストへ転送する構成には未対応。
- `CANVAS_BASE_URL` と `CANVAS_REVIEW_ORIGIN` は同じHTTPSオリジンに設定する。テストだけloopback HTTPを使用する。
- CSVは実読取1MB・100答案まで、JSONメタ情報も読取上限あり。通信はキャッシュ無効・各要求20秒以内。Content-Lengthだけを信用しない。
- CSVのヘッダー、設問ID、配点、列数、正の受講者番号／受験回、重複答案、得点範囲・合計、小数精度を検査する。UTF-8 BOM、引用符内の改行／カンマ、二重引用符に対応する。
- 空欄は未採点として扱い、0点と区別する。答案0行なら0件のまま保存し、欠席者の0点を生成しない。
- 氏名・回答文・セクション情報を破棄してから、既存の在籍・一意な本人対応・コース所属の検証と、確認待ち保存へ渡す。原本CSVは永続化しない。
- 新規候補にはレポートID、ファイルID、両更新日時、取得日時、SHA-256、全受験回であること、`freshness: unconfirmed` を記録。URLや認証値は保存・返却しない。
- 同じ答案・同じ得点の再取得は重複としてスキップする。初回の保存日時・期限・取得元は上書きしない。取得の監査記録は別途追加する（0件や重複だけの場合も記録）。
- 再採点による異なる得点は別候補として残す。最新の受験回・最高点・公式成績のどれを採用するかを自動決定しない。

## 検証で確認したこと

- 稼働中Canvasの許可済み架空デモ答案だけを、同じ実装で読み取り専用取得。12問すべてが前回検査済みの変換結果と一致した。DBアクセス・成績変更・コード配備なし。
- 隔離した架空Canvas＋PostgreSQLで、取得→変換→確認待ち保存→再表示を確認。正常、入力不正、別コース／担当外／受講者／ゲスト、サイズ境界、未生成／生成中、不正CSV、本人対応不一致、0件、再送を検証。
- 詳細な件数と実行結果は `verification.json`。3表示条件の確認はブラウザーの画面サイズ・タッチ模擬であり、Quest 3実機ではない。
