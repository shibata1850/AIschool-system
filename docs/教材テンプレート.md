# 教材の書き方（テンプレート）

- 作成: 2026-09-08（隘路）。柴田さまが教材を書き始めるときに迷わないための雛形
- 前提: 2026-09-04 合意 —「**機械で読める形（Markdown または Canvasのページ）を正にする**」
  （未決事項 #3）。PowerPoint・Canva・画像PDFは**見せる用の派生**として別に作ってよいが、
  文章の「正」はこちら
- なぜ形式を縛るか: 1本の教材が **4役** をこなすため
  1. 受講生が読む（Canvasで配信）
  2. AI講師が止まったときの誘導先（S3の静的教材モード・F2②）
  3. クラウドのAI講師（Claude）に読ませる知識（「STEP03では何をしますか」に答えられるようにする）
  4. 講師用ローカル教材AI（要望リスト #10）が**出典つき**で引く元

## 1. ファイルの単位と名前

- **1トピック1ファイル**。パンフレットv2（NGAS_A4_5P_v2）のSTEPを単位にする
- ファイル名は `STEP03.md` のように **STEP番号だけ**（日本語のファイル名は避ける。
  Canvasのページに書く場合はページ名を「STEP03 ○○」にする）
- 1ファイルの目安は **A4で1〜2枚（1,500〜3,000字）**。長くなるなら
  `STEP03-1.md` `STEP03-2.md` と分ける。**分ける理由**: AIに渡すのは「関係する
  ファイルだけ」にしたいため。全部を毎回渡すと遅く・高く・不正確になる

## 2. 見出しの型（この順で・省略可・追加可）

```markdown
# STEP03 ○○○○（STEP名は パンフレットv2 の表記どおり）

## この回のゴール
（1〜3行。「受講生が何をできるようになるか」で書く。「〜を学ぶ」ではなく「〜を作れる」「〜を書ける」）

## 前の回までにできていること
（この回に入る前提。箇条書き）

## 手順
1. ○○する
2. ○○する
   - 画面のどこを押すか、何を入力するか
3. ○○する

## 提出物
（何を、どの形で、いつまでに。無ければ「なし」と書く）

## よくある間違い
- ○○してしまう → ○○する
（第1期の会話ログ（S11）から随時足していく。ここが講師の属人性を下げる場所）

## 講師メモ
（受講生には見せない補足。時間配分・つまずきやすい人への声かけ。Canvasに載せる場合はこの節を外す）
```

見出しの文言は**全ファイルで同じ**にする（「手順」を「やり方」に変えない）。
AIと講師用AIは、この見出しを頼りに「STEP03 ＞ 提出物」のように出典を指す。

## 3. 書くときの約束

| 約束 | 理由 |
|---|---|
| **図の中の文字は本文にも書く** | 画像の中の文字はAIに読めない。図は補助、文章が正 |
| 固有名詞の表記を揃える（BASE44／Base44 を混ぜない） | AIが別物として扱う。会話ログから教材へ還元するときの検索にも効く |
| **実在の企業名・個人名・連絡先を書かない**。事例は架空化する | CLAUDE.md 2章。教材はAIに渡すため、書いた瞬間に外部（Claude API）へ出る |
| 「大丈夫」「問題ない」と断定する文を書かない。判断が要る箇所は「講師に確認」と書く | AI講師にも断定を禁じている（tutor.ts）。教材が断定すると、AIがそれを根拠に断定する |
| BASE44の**操作手順は最小限**にし、「BASE44の画面の案内に従う」と書く | BASE44は外部SaaSで画面が変わる。追随して直し続ける工数が出る（CLAUDE.md 11章） |
| 1文を短く。専門用語には言い換えを添える | 対象は企業・行政の社員。CLAUDE.md 2章5 |

## 4. どこに置くか

- **正**: Canvasのコースの「ページ」（受講生が読む場所。APIで文字として取り出せる）
  または本リポジトリ外の教材フォルダ（Markdown）。**本リポジトリには置かない**
  （教材コンテンツ管理はeラーニング側の範囲・CLAUDE.md 13.1。ここは読むだけ）
- AI講師が止まったときの誘導先URL（`STATIC_MATERIAL_URL`）には、そのときの回の
  Canvasページを設定する（手動対応リスト B20）

## 5. 最初の1本を書いたら

1本できた時点で隘路に見せてください。**AIに読ませて「STEP03では何をしますか」と
聞いて答えられるか**を試し、見出しや分量をこの雛形側に反映します。
10本書いてから直すより、1本で直す方が安い。
