### F2① 応答時間の実測（2026-09-02・本番サーバー）

| 回 | elapsedMs | provider / model | outcome |
|---|---|---|---|
| 1 | 4268 | claude / claude-haiku-4-5-20251001 | ok |
| 2 | 4473 | 同上 | ok |
| 3 | 4212 | 同上 | ok |

平均 4318ms・最大 4473ms。**3件とも5000msを下回るが、余裕は最大値で約10%**。

**判定を出す前に片付けるべき2点**:

1. **基準の書き方が文書内で食い違っている**
   - 要件定義書 8章（非機能）: 「AI応答の**開始**まで5秒以内」
   - 画面仕様書 S3: 「5秒以内に**応答開始**」
   - 要件定義書 9.2 F2①（受け入れ基準）: 「質問→フィルタ経由→**応答表示**が5秒以内」

   現在ストリーミングをしていないため「開始 ＝ 表示完了」で、どちらで読んでも
   同じ4.3秒になる。**厳しい側（応答表示）で読んでも通っている**が、
   検収時に解釈が割れないよう、どちらが正かを先に確定させておくべき。

2. **サンプルが3件しかない**
   受け入れ基準は「**10問中9問以上**」。正式判定には最低10問の実測が要る
   （受け入れ当日の講師トレーニング中の操作で足りる）。

**時間の内訳**: Haiku 4.5 で4.3秒かかっているのは、回答が300〜400文字と長く
**出力トークンの生成時間が支配的**なため。短くすれば比例して縮む。

**未測定のリスク**: 上記は単独利用の値。**16名が同時にAI講師へ質問した場合は未測定**
（APIへの発行はI/O待ちのため大きくは変わらない見込みだが、実測はしていない）。
