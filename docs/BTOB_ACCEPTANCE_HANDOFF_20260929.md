# BtoB研修：実装棚卸しと通し確認

更新：2026-09-29。コードと保存済み作業記録の照合。今日の本番全体再検証を意味しない。

## 方針

- 必要な実装を先に揃え、利用者による全体の通し確認はまとめて行う。
- 機能修正時には関連E2Eを都度実行する。無関係な全件テストの繰り返しは避ける。
- 文書のみの変更ではE2Eを再実行しない。
- 公開、成績の正式採用、外部連携の契約は実装完了とは別に判断する。

## 残作業の区分

- 人による通し確認：以下の手順で操作性・表示・業務の流れを確認し、不具合があれば関連E2Eを追加して修正する。
- 運用設定：STEP02〜09の小テスト公開は内容確認後に判断する。非公開のままでは受講生の受験確認は完了できない。
- 成績運用：本人表示と総合到達度への採用を区別する。正式採用の本番確認は対象受講者・小テスト・受験回・対象授業週を明示して承認してから行う。
- 外部依存：eラーニングのSSO・削除伝播は先方仕様との調整が必要。今回のBtoBホーム完了判定と混ぜない。
- 保留：Quest日本語音声の代替対応。ユーザー合意により低優先度。

## 人による通し確認手順

対象はCanvasコース2「BtoB研修｜BASE44完結プラン」。実受講者のデータを作らず、既存の架空アカウントを使う。管理者と受講生は別ブラウザープロファイルで開くと取り違えを避けやすい。

| 順 | 操作 | 期待する結果 |
|---|---|---|
| 1 | 講師または管理者でコース2の「AI講師・演習」→「授業設定」 | BtoB研修型、現在の授業は未選択。10回の授業名と教材リンクが表示される |
| 2 | 第5回・第6回の設定を確認 | 第5回は実施チェックなし・小テスト選択不可。第6回は実施チェックあり・小テスト130 |
| 3 | 現在の授業を第5回にして保存 | 「保存しました」。ほかの設定は変わらない |
| 4 | 架空受講生でコース2からLTI起動 | 第5回の名称と「小テスト：この回は実施しません」。講師・管理者メニューは出ない |
| 5 | 教材を開く | STEP05が別タブで表示され、元の研修ホームが残る |
| 6 | 講師が現在の授業を第1回に変更し、受講生で開き直す | 第1回の教材と小テスト100のリンク。小テストが別タブで開く |
| 7 | 必要なら架空受講生で受験し、講師がCSVを取得・Canvasと照合 | 新しい受験回・点数が一致する。既存の採用結果は勝手に置き換わらない。受験はデータを作るため意図した場合のみ行う |
| 8 | 講師が対象を確認し本人表示に採用、受講生が小テスト記録を確認 | 選んだ受験回・合計・技能別得点・表示期限が一致。本人表示だけでは正式採用にならない |
| 9 | 正式採用を試す場合のみ対象週を指定して採用 | 総合到達度に使う小テスト履歴へ反映。正式採用の承認がなければこの項目は保留 |
| 10 | 現在の授業を未選択に戻す | 設定を復元し、代理ログインを使った場合は解除する |

受験・採用・取り下げには履歴が残る。確認後にデータを削除して片付けない。問題は「操作したアカウント、授業回、操作、表示文言、期待との差」を記録する。秘密情報は添付しない。
