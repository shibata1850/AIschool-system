# 課題割当（2026-09-10）

## 対象範囲

既存のカスタム層課題を、講師が選択した受講生へ配布する。課題新規作成・Canvas課題の自動取り込み・全員への自動配布は含まない。

1. 受講生が対象Canvasコースの「AI講師・演習」を起動する。
2. 講師が同じコースから起動し、講師用メニュー「課題の割当」を開く。
3. 既存課題と受講生を選び「割り当てる」を押す。
4. 受講生がホームを開き直すと未着手課題が表示される。

## 安全性

- コースは署名検証済みLTIセッションから取得する。リクエスト本文で変更できない。
- 受講生・ゲスト・コース情報のない起動は割当不可。別コースの起動記録しかない受講生への割当も不可。
- 名簿はLTI起動履歴であり、Canvasの現在の在籍状態をリアルタイム取得する機能ではない。退会時のデータ削除ではstudent_coursesも外部キーで削除される。
- 既存課題は共通カタログ扱い。既存の提出は課題ID＋受講生ID単位なので、同一課題を別コースで重ねて割り当てても既存提出を保持する。
- 割当は課題行のロックで直列化。同じ組み合わせを再度選んでも増やさず、提出・確定成績を更新しない。
- 監査ログと割当は同一トランザクション。監査に名前や本文を保存しない。
- 既存名簿へコースを推測して補完しない。0010適用後、受講生の再起動が必要。

## 表示

- 未割当は「まだ課題が割り当てられていません。」、割当済み全件完了時だけ「すべて完了しています。」。
- 採点待ち・Canvas未反映一覧の提出者は名簿の表示名。不明なら「名簿未登録（ID）」。
