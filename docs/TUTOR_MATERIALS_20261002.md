# 教材参照AIと今後の連携

## 今回の実装

- STEP01〜09の公開説明170節を、版管理されたJSONとして同梱。
- 原稿は `work/vr-canvas-handoff/docs/step01/pc/source/scenes.json` の `speech_text` と、STEP02〜09 `source/lesson.json` の `teaching` のみ。
- 講師用正答、評価問題集、個人の答案・ヒアリング回答は取り込まない。
- 質問は既存の個人情報マスキング・入力フィルタを通した後に検索。最大3節、1節2400文字まで。
- AIには教材を資料として渡し、資料内の指示を実行しないこと、記載外の学校運用を推測しないことを指示する。
- 回答画面の「参照教材」はAIへ渡した資料を示す。回答内容が資料に完全に裏付けられていることを自動保証する表示ではない。
- 教材の更新は自動追従しない。原稿確認後 `node scripts/import-tutor-materials.mjs <教材リポジトリ>` で再生成し、差分確認・再配備する。各節に元ファイルのSHA-256を保持する。
- 個別の小テスト分析・採点・復習問題選定は行わない。成績による授業進行制限も追加しない。

## 残る接続作業

eラーニングはBASE44試作段階であり、分析処理は将来実装される。受信API・認証・受講生ID対応が未確定のため、答案を外部へ送信する機能は有効化していない。

接続時に合意する事項:

1. 受信するシステムと専用認証。Canvas管理者トークンは共有しない。
2. 受講者・コース・小テスト・受験回・設問・教材節ID・原稿版の対応。
3. 採点確定/未採点、再採点、再受験、取り下げ、期限切れ、受講者削除の扱い。
4. 氏名・所属・連絡先を送らず、学習支援に必要なデータのみを送る。自由記述は別途マスキング・送信可否判断が必要。
5. 重複受信を防ぎ、通信失敗時は授業を止めず未連携を表示する。
6. eラーニングが返す助言と参照教材を本人だけが確認できる導線。

接続先の未完成を、Canvas側にE4を重複実装する理由にしない。既存の単元参照・到達度受信APIと、今回の教材対話は別機能である。
