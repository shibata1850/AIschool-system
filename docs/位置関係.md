## 2. システム1: クラウドキャンパス（本リポジトリ）

```
SOFTDOING（発注者・補助事業者）
  │ 発注書 SD-2026-0720-001 / 見積 No.13020653 ¥6,732,000（税抜）
  │ 補助金: 新事業進出補助金
  ▼
有限会社ノーティ（受注者・納品主体）
  │ 再委託
  ▼
隘路さま（個人事業主）
  │ 実装
  ▼
本リポジトリ（SOFTDOINGのGitHub org・さくらのクラウドで稼働）
```

### 2.1 この構造だと外注費の扱いは変わらない

**成果物はノーティの納品物**であり、その実装をノーティの再委託先である隘路さまが
担当している、という整理になる。作業場所がSOFTDOINGの環境・リポジトリであることは、
**成果物の帰属を変えない**（先方要件定義書 第9章も「さくらのクラウド契約・作業アカウント
発行・ドメイン/DNS」は発注者=SOFTDOINGの役割と明記している）。

したがって「補助金事務局への確認は不要」という判断は、**この構造である限り筋が通る**。
`CLAUDE.md` 10章が求めていた「参照実装を本番採用する場合の確認」は、
**そもそも参照実装ではなく最初からノーティの納品物だった**、という整理になるためである。

### 2.2 ただし1点、契約側の確認が要る

**再委託が元請契約で認められているか**である。補助金を用いる委託契約では、
再委託に事前承認を求める条項が置かれることがある。これはSOFTDOINGとノーティの
契約書の問題で、本リポジトリの実装とは無関係だが、**検収前に一度、契約書の
再委託条項を確認しておくべき**である（→ 未決事項 #15）。

## 3. システム2: eラーニングシステム

```
SOFTDOING（発注者・補助事業者）
  │ 発注書 SD-2026-0821-004 / 見積 No.13020711 ¥609,800
  │ 補助金: 岩手県中小企業賃上げ補助金
  ▼
有限会社ノーティ（受注者）
  │
  ？ ここから先の実装実態が、上の契約の流れと一致していない
  │
  ├─ BASE44での実装 ……… **SOFTDOINGの従業員（予定）**
  ├─ GitHub→Codex→さくらへの移行 ……… 隘路さま
  └─ 移行後の調整 ……… 同従業員
```

### 3.1【要確認】外注費の計上と実装実態が一致しない可能性がある

システム1と**構造が違う**点に注意が要る。

| | クラウドキャンパス | eラーニング |
|---|---|---|
| 実装者 | ノーティの再委託先（隘路さま） | **SOFTDOINGの従業員（予定）** |
| ノーティへの外注費として | **成立する**（受注者の再委託先が作った） | **成立するか不明**（発注者自身の従業員が作っている） |

**自社の従業員が作ったものは、自社の人件費であって外注費ではない。**
ノーティへ ¥609,800 を外注費として支払い・計上する一方、実装を
SOFTDOINGの従業員が行うと、**証憑（外注費）と実装実態が一致しません**。
これは `CLAUDE.md` 10章が「絶対条件」として挙げている点にそのまま該当する。

考えられる整理は次のいずれかで、**どれが実態かをはっきりさせる必要がある**。

| 整理 | 内容 |
|---|---|
| (a) ノーティが実装する | 発注どおり。SOFTDOINGの従業員は関与しない |
| (b) 従業員はノーティの再委託先として動く | その従業員がSOFTDOINGを離れ、または兼業としてノーティから受注する。**雇用契約・就業規則との整合が必要** |
| (c) 外注費ではなく自社人件費で計上する | 発注書・見積の建付けを変える。**賃上げ補助金の交付申請内容との整合確認が必須** |
| (d) その他 | — |

→ **未決事項 #16 として起票**。判断者は柴田さま（必要に応じて補助金事務局・専門家）。

### 3.2 機能境界（13.1）は、実装者が誰でも変わらない

「両方を隘路さまが管理するので気にしなくてよい」というお話があったが、
**二重計上の判定は管理者ではなく、どの補助金で計上したかで決まる**。

- クラウドキャンパス = **新事業進出補助金**
- eラーニング = **岩手県中小企業賃上げ補助金**

同じ機能が両方にあると、**別々の補助金に同じものを計上した**と判断される。
むしろ**同じ人が両方を作った場合のほうが、「なぜ両方に同じ機能があるのか」を
説明しにくくなる**。`CLAUDE.md` 13.1 の禁止範囲は維持する。
